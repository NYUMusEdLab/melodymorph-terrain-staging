The bass package is an additional instrument from the same pinned library. MusEDLab local references: aQWERTYon uses MusyngKite; teacher-pilot-local explicitly lists the earlier piano/vibraphone/nylon-guitar instrument set.
Pluck maps to acoustic_guitar_nylon, a prototype choice from the existing set, not a claim about MelodyMorph's original sample.
Round bells use acoustic_bass at Alex’s request. This is a licensed replacement sound, not Eric Rosenbaum’s original sample. The round-bell timbre retains the internal legacy key piano for saved-landscape compatibility.

Electric Piano uses electric_piano_1; Piano uses acoustic_grand_piano, both unchanged from the same pinned MusyngKite library. These replacement samples do not claim original sound parity.

Bowed uses violin-mp3.js, redistributed unchanged from the same pinned MusyngKite revision under CC BY-SA 3.0. It is a violin replacement sound, not an erhu or an original MelodyMorph sample. Each tap plays a finite bowed note. All six banks support C3–C6.
